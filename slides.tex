\begin{frame}{O que é Nix?}
	\begin{itemize}
		\item Nix é uma DSL (\foreignlanguage{english}{\emph{Domain Specific Language}}) puramente funcional, usada para definir pacotes utilizados pelo gerenciador de pacotes.
		\item Nix também é um gerenciador de pacotes que utiliza um mecanismo de \emph{hashing} para instalar pacotes em diretórios únicos e imutáveis
		\item NixOS é uma distribuição do sistema operacional Linux
	\end{itemize}
\end{frame}
